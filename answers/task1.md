# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理
2. 编译
3. 汇编
4. 链接

建议控制在 300～500 字，不需要展开复杂细节。

## 整体流程
C 程序不能直接运行，必须经过四个阶段：**预处理 -> 编译 -> 汇编 -> 链接**。

## 第一步：预处理（gcc -E）
把 `#include` 引用的头文件内容展开进来，处理 `#define` ，去掉注释。
运行命令：
`gcc -E hello.c -o hello.i`
生成文件：`hello.i`，`#include`引用的头文件被展开了，其他的代码没有变化。

## 第二步：编译（gcc -S）
把 C 代码翻译成汇编代码。汇编是一种更接近机器底层的语言，还是文本格式。
运行命令：
`gcc -S hello.i -o hello.s`
生成文件：`hello.s`，里面是一行行的汇编指令（如 mov、call）。

## 第三步：汇编（gcc -c）
把汇编代码翻译成机器码（二进制指令），生成目标文件。
运行命令：
`gcc -c hello.s -o hello.o`
生成文件：`hello.o`，这已经是二进制文件，用 cat 查看会显示乱码。此时程序还缺外部函数（比如 printf）的代码，不能运行。

## 第四步：链接（gcc hello.o -o hello）
把目标文件和系统库（比如 C 标准库）连接在一起，拼成完整的可执行程序。
运行命令：
`gcc hello.o -o hello`
生成文件：`hello`，这就是最终可以直接运行的程序。

## 观察到的现象
- `hello.i` 相比 `hello.c` 只有头文件被展开了。
- `hello.s` 是汇编代码。
- `hello.o` 是二进制。
- 最终生成的 `hello` 可以直接运行，输出 `Hello, World!`。
